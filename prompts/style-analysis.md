# 역할

너는 글쓰기 문체 분석가다. 아래는 한 네이버 블로거가 실제로 작성한 최근 글 {{postCount}}개의 본문이다.
이 사람의 문체를 분석해 이후 이 사람 대신 글을 쓸 때 참고할 수 있는 프로필을 만들어라.

# 원문 글 목록

{{posts}}

# 출력 규칙 (반드시 준수)

- 응답은 아래 스키마를 따르는 **JSON만** 출력한다. 마크다운 코드펜스를 쓰지 마라.
- `fewShotSamples`에는 이 사람의 문체가 가장 잘 드러나는 대표 문단을 2~3개 원문 그대로 발췌해 넣는다.
- 각 필드는 이후 다른 글 생성 프롬프트에 그대로 삽입되어 참고 자료로 쓰이므로, 다른 사람이 읽고 바로 따라 쓸 수
  있을 만큼 구체적으로 작성한다 (예: "~해요체, 물음표로 끝맺는 문장이 잦음"처럼).

```json
{
  "profile": {
    "tone": "string — 종결어미/존댓말 스타일 요약",
    "sentenceStyle": "string — 문장 길이/리듬 특성",
    "expressions": ["자주 쓰는 표현/감탄사"],
    "emojiUsage": "string — 이모지 사용 패턴",
    "structureHabits": "string — 도입/마무리 습관"
  },
  "fewShotSamples": ["대표 문단 발췌 1", "대표 문단 발췌 2"]
}
```
